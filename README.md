# Final Project — Summer Camp

## Data Analysis Project

This project was developed as part of the Summer Camp training program.

The objective of the project is to explore, clean, analyze, and visualize data using Python and Pandas.

## Project Files

The repository contains the following files:

* `final_priject.ipynb` — Jupyter Notebook containing the data analysis, code, results, and visualizations.
* `InternetSales.xlsx` — Internet sales dataset.
* `Products.csv` — Products dataset.
* `customers.json` — Customers dataset.
* `SalesTerritory.parquet` — Sales territory dataset.

## Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* Matplotlib

## Project Workflow

The notebook includes several stages of data analysis:

1. Importing the datasets.
2. Exploring the data.
3. Cleaning and preparing the data.
4. Performing data analysis using Pandas.
5. Grouping and aggregating data.
6. Creating data visualizations.
7. Interpreting the results.

## Visualizations

The project includes visualizations such as:

* Bar charts
* Pie charts
* Sales distribution visualizations

## How to Run the Project

1. Clone or download this repository.
2. Make sure Python and Jupyter Notebook are installed.
3. Install the required libraries:

```bash
pip install pandas matplotlib openpyxl fastparquet
```

4. Open `final_priject.ipynb` with Jupyter Notebook or VS Code.
5. Run the notebook cells sequentially.
